# Skills tiers installés dans ce projet

Copies de skills publics (sans modification, sauf l'adaptation de chemin signalée pour ui-ux-pro-max) (licence MIT, textes dans `_licences/`). Les skills d'Emil Kowalski et de LottieFiles sont des consignes en Markdown seulement. **`taste-skill` contient aussi des scripts Node**, relus avant installation (voir ci-dessous) ; rien ne s'exécute à l'installation : ils ne tournent que si l'agent les lance, avec les autorisations habituelles.
